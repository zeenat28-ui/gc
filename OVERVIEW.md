# GreenCode Auditor

A public, rebrandable software carbon auditing app. Developers and engineering teams paste a public GitHub repo or a code snippet and get a Green Score, yearly energy and CO₂e estimates, and a list of energy-heavy code with suggested fixes. It also includes a provider-neutral carbon calculator.

The owner sells it either hosted (customers sign up on the owner's domain) or by letting buyers copy it into their own Zite workspace. The Admin area (Branding & Customers) lets each reseller set the name, tagline, logo, plan prices and limits, and change customer plans by hand (no payment provider yet). Nothing depends on Amazon/Alexa or an outside AI provider — fixes come from the database's built-in AI.
